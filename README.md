# أبطال تحدي الدراسات الاجتماعية

نسخة أولية مستقلة تعمل في المتصفح دون منصة بناء بالذكاء الاصطناعي.

## التشغيل
1. فكّي ضغط الملف.
2. افتحي `index.html` في متصفح حديث.
3. أضيفي الفرق ثم سجّلي الدرجات من صفحة تسجيل الدرجات.

## ما تتضمنه النسخة
- لوحة متابعة مختصرة.
- إدارة الفرق للصفوف الرابع والخامس والسادس.
- ست جولات بمهام مناسبة للمسابقة.
- تسجيل درجات بمعايير مجموعها 100.
- لوحة صدارة تراكمية مستقلة لكل صف.
- بطاقات تحدٍ قابلة للطباعة.
- إصدار شهادة تقدير قابلة للطباعة.

## تنبيه مهم
هذه نسخة تجريبية محلية؛ تحفظ البيانات في `localStorage` على الجهاز والمتصفح الحالي فقط. لا توجد مزامنة بين الأجهزة ولا حسابات دخول ولا نسخ احتياطي مركزي. قبل استخدامها الفعلية مع بيانات الطالبات، يلزم ربط قاعدة بيانات مشتركة وإضافة صلاحيات ونسخ احتياطي واختبارها.
